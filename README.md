#  PlaceAI – AI-Powered Campus Recruitment & Placement Management System

> Helping placement cells reduce **70% of manual work** by automating student-recruiter matching and managing the complete campus hiring process from one intelligent dashboard.

---

##  Overview

PlaceAI is a modern Campus Recruitment & Placement Management Platform designed for colleges, universities, placement cells, and recruiters.

The platform streamlines the entire campus hiring workflow—from student registration and resume management to recruiter job posting, AI-based candidate matching, application tracking, and placement analytics.

Instead of manually filtering hundreds of student profiles, recruiters receive automatically matched candidates based on the required skills, CGPA, branch, experience, and other eligibility criteria.

---

##  Problem Statement

Traditional campus placement processes involve:

- Manual resume screening
- Spreadsheet-based student management
- Time-consuming eligibility verification
- Poor communication between recruiters and placement cells
- No centralized recruitment dashboard
- Difficult placement reporting and analytics

These challenges consume significant time and increase administrative workload.

---

##  Solution

PlaceAI automates the complete campus recruitment lifecycle by providing:

- AI-powered student-job skill matching
- Recruiter Management Portal
- Student Portal
- Placement Cell Admin Dashboard
- Resume Management
- Job & Internship Management
- Placement Analytics
- Candidate Shortlisting
- Secure Authentication
- Real-time Recruitment Tracking

#  Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/PlaceAI.git
```

Navigate into the project

```bash
cd PlaceAI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the server

```bash
uvicorn app.app:app --reload
```

Visit

```
http://localhost:8000
```
